# 01.1 — Login Líder (Passthrough)

**Tipo:** Página de passagem — infraestrutura já implementada (Stories 2.1/2.2 merged).
**Dispositivo:** Mobile Android gama média-baixa (Moto G4/G5), PWA na home screen.
**Contexto:** Quarta-feira, 7h12. Líder no ônibus ou mesa da cozinha, 1–3 min disponíveis.

---

## Estados relevantes para o Cenário 01

### Estado A: Sessão ativa (caminho esperado)

- JWT válido + high-entropy session (Story 1.8)
- PWA abre → skip transparente → redirect direto para `/app/gestao/radar`
- **Zero interação do líder** — tempo: <1s
- Este é o caminho dominante no hábito semanal consolidado

### Estado B: Sessão expirada

- JWT inválido/expirado → tela de login renderizada
- Email preenchido via "lembrar-me" (localStorage)
- Google One Tap disponível como alternativa de 1 toque
- **Máximo 2 toques** para entrar: (1) digitar senha ou (2) tap Google One Tap
- Pós-login → redirect para `/app/gestao/radar` via ExperienceResolver (role `lider` → experiência `gestao`)

### Redirect pós-login

- ExperienceResolver (architecture.md) resolve a rota por role:
  - `lider` → `/app/gestao/radar`
  - `admin_tenant` → `/app/admin/`
  - `participante` → `/app/consumo/grupos`
- **Nunca** redirecionar para home genérica — o líder cai direto no radar
