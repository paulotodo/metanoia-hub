## Overview

**Page Purpose:** Registrar a ação de cuidado em 1 frase livre e fechar o loop. Um campo de texto, um botão. Confirmação seca com gratidão. O líder sai do app sabendo que agiu — e o sistema registra o evento que alimenta o North Star metric.

**User Situation:** Líder decidiu agir. Está no ônibus ou na mesa da cozinha, com o polegar pronto. Quer registrar rápido o que vai fazer ("vou mandar mensagem hoje à noite") e fechar o app. Não quer formulário, não quer categorização, não quer workflow. Uma frase e tchau.

**Success Criteria:** Em ≤15 segundos, líder digita a ação, toca salvar, vê a confirmação e sai do app. A sensação é de conclusão, não de obrigação. O sistema gera `radar.action.recorded` → +1 para o North Star metric.

**Entry Points:**
- (1) Tap em "Registrar cuidado" na 01.4 (navegação primária — via perfil)
- (2) Tap em "Registrar cuidado" na 01.3 (atalho direto — pula perfil)
- (3) Deep link `/app/gestao/radar/{participantId}/cuidado`

**Exit Points:**
- (1) Salvar → confirmação → fechar app ou voltar ao radar
- (2) Back/swipe → página anterior (01.4 ou 01.3, depende da origem)
- (3) Tabs → navegação lateral

**Route Hierarchy:**
- 01.3: `/app/gestao/radar/{participantId}` — detalhe do sinal
- 01.4: `/app/gestao/radar/{participantId}/perfil` — perfil relacional
- 01.5: `/app/gestao/radar/{participantId}/cuidado` — registro de ação (esta página)

## Technical Notes

- **Rendering:** CSR (autenticada, `/app/`). Não indexável.
- **Data fetching:** Contexto mínimo (nome + grupo) via navigation params ou `useParticipantContext(participantId)`. Cache-first.
- **Form state:** React state local (useState). Não Zustand — escopo de formulário único, sem compartilhamento.
- **Submit:** POST `/api/v1/care-actions` com body `{ participantId, groupId, signalType, note }`. Response 201 com `{ data: { careActionId, recordedAt } }`.
- **Domain event:** Backend emite `radar.action.recorded` com `{ eventId, eventType, version: 1, tenantId, timestamp, data: { careActionId, leaderId, participantId, groupId, signalType }, metadata: { source: "web" } }`.
- **North Star metric:** Evento conta para `% semanas-líder com ≥1 ação orientada pelo radar em ≤48h`. Cálculo no backend (analytics bounded context).
- **Multi-tenancy:** `tenantId` via AsyncLocalStorage. Validação: participante pertence ao tenant ativo do líder. Backend valida ownership.
- **Performance:** TTI ≤2s. Auto-focus dispara após hydration para evitar layout shift.
- **Accessibility:** WCAG AA. Label associado ao textarea via `htmlFor`. Botão desabilitado usa `aria-disabled` (não `disabled` nativo — permite feedback ao toque). Dialog usa `role="alertdialog"` + focus trap. Confirmação usa `aria-live="polite"` para screen readers.
- **Keyboard handling:** Botão "Salvar" posicionado acima do teclado virtual via `position: sticky` bottom ou scroll into view. Testado em Moto G4 viewport.
