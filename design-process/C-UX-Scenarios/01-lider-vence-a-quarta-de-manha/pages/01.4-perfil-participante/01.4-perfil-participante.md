## Overview

**Page Purpose:** Memória relacional mínima — relembrar ao líder quem é essa pessoa antes de agir. Última conversa registrada, última oração, próximo marco do grupo. Nada mais. Não é dashboard, não é histórico, não é perfil social. Só o que ajuda a relembrar a pessoa com dignidade.

**User Situation:** Líder acabou de ver o sinal na 01.3 e tocou "Ver essa pessoa". Quer lembrar rapidamente: "quando foi a última vez que falei com essa pessoa? O que estava acontecendo?" Está no ônibus, tem segundos antes de decidir agir. Precisa de contexto relacional, não de dados.

**Success Criteria:** Em ≤10 segundos, líder relembra o contexto relacional da pessoa e decide: registrar cuidado agora (→ 01.5) ou voltar ao radar. A tela reforça a confiança de que o sistema ajuda a lembrar, não a vigiar.

**Entry Points:**
- (1) Tap em "Ver essa pessoa" na 01.3 (navegação primária)
- (2) Deep link `/app/gestao/radar/{participantId}/perfil`

**Exit Points:**
- (1) "Registrar cuidado" → 01.5 Loop Fechado (`/app/gestao/radar/{participantId}/cuidado`)
- (2) Back/swipe → 01.3 Detalhe do Sinal (estado preservado)
- (3) Tabs → navegação lateral

**Route Hierarchy:**
- 01.3: `/app/gestao/radar/{participantId}` — detalhe do sinal
- 01.4: `/app/gestao/radar/{participantId}/perfil` — perfil relacional (esta página)
- 01.5: `/app/gestao/radar/{participantId}/cuidado` — registro de ação

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| **Default (com memórias)** | Dados ok, ≥1 memória relacional existe | Layout completo com seções de memória visíveis | Todas |
| **Default (sem memórias)** | Dados ok, nenhuma memória relacional | Header + EmptyMemoryState + Timeline + CTA | Todas |
| **Loading** | Primeiro carregamento | Header com nome+pill (dados de navegação). Memória + Timeline: skeleton shimmer. | Back, tabs. Botão disabled. |
| **Error (network)** | Fetch falhou, sem cache | Header + card erro "Não foi possível carregar o perfil" + retry | Back, retry, tabs |
| **Error (network+cache)** | Fetch falhou, cache disponível | Layout normal + banner offline dismissable | Todas (cached) |
| **Error (not found)** | participantId inválido ou não pertence ao líder | Redirect → 01.2 + toast "Participante não encontrado" | — |

**Transitions:**
```
[Loading] → ok, com memórias → [Default (com memórias)]
[Loading] → ok, sem memórias → [Default (sem memórias)]
[Loading] → fail, no cache → [Error network]
[Loading] → fail, cache → [Error network+cache]
[Loading] → not found → [Error not found] → redirect 01.2
[Error network] → retry ok → [Default *]
```

## Technical Notes

- **Rendering:** CSR (autenticada, `/app/`). Não indexável.
- **Data fetching:** TanStack Query — `useParticipantProfile(participantId)`. Cache-first. Query key inclui `participantId`.
- **Navigation state:** Nome + pill + groupId passados via navigation params da 01.3 → header renderiza instantâneo (sem fetch). Dados de memória relacional carregam em background.
- **Multi-tenancy:** `tenantId` via AsyncLocalStorage. Validação: participante pertence ao tenant ativo do líder. Backend valida ownership antes de retornar dados.
- **Performance:** TTI ≤2s. Header imediato (dados de nav), memória relacional com skeleton.
- **Accessibility:** WCAG AA. Cor + ícone na pill. Dots com aria-labels individuais. Seções de memória com headings semânticos (H3) para navegação por screen reader. Empty state anunciado via aria-live.
- **Data privacy:** Notas de conversa e oração são registradas pelo próprio líder — dados first-party. Nenhuma nota gerada pelo sistema.
