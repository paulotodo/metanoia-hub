## Overview

**Page Purpose:** Mostrar ao líder, em menos de 30 segundos, quem dos seus grupos precisa de atenção esta semana — com sinais priorizados por relevância, em linguagem pastoral, sem imperativo nem diagnóstico. Panorama cross-group primeiro, filtro por grupo individual como ação secundária.

**User Situation:** Líder abre o app na quarta ~7h (ônibus ou mesa da cozinha), atenção fragmentada, 1-3 min disponíveis. Expectativa: resposta binária imediata — "tem algo?" → sim/não, e se sim, "quem?". Medo de ser pego de surpresa na reunião de quinta. Esperança de sair em 30s sabendo quem precisa de um gesto. Variante pós-reunião: mais focado mas cansado, espera dados frescos.

**Success Criteria:** Líder identifica em ≤30s se há sinais de atenção e, se houver, toca no sinal mais urgente iniciando o fluxo de cuidado. Nas semanas boas, sai com alívio genuíno (Inbox Zero Pastoral). Métrica: `% semanas-líder com ≥1 ação orientada pelo radar em ≤48h` (meta ≥60%, DDR-18).

**Entry Points:**
- (1) Redirect pós-login via ExperienceResolver (role `lider` → `/app/gestao/radar`)
- (2) Sidebar / Bottom tabs — item "Radar" na navegação principal (Story 1.8)
- (3) Retorno do fluxo de cuidado (01.5) — volta ao radar para próximo sinal
- (4) Retorno pós-reunião (Cenário 02) — após fechar sala LiveKit + reflexão

**Exit Points:**
- (1) Toque no sinal → 01.3 Detalhe do Sinal
- (2) Navegação lateral → outras telas do líder (via tabs)
- (3) Fechar app (Inbox Zero — nada a fazer)
- (4) Tenant switcher → radar de outro tenant (Cenário 08, DDR-12)

**OBJECT ID:** `01.2-S1`

|----------|-------|
| Component | button (pill) |

| Translation Key | PT-BR |
|-----------------|-------|
| `radar.pill.urgent` | "{count} {count, plural, one {precisa de} other {precisam de}} cuidado" |
| `radar.pill.delta` | "(+{delta} {delta, plural, one {novo} other {novos}})" |

| Behavior | Description |
|----------|-------------|
| 1º toque | Scroll suave até SectionDivider 🔴. Pill → `active`. Outras seções continuam visíveis. |

| Toque outra pill (durante filter) | Restaura panorama + scroll para nova seção. |

| State | Visual | Condition |
|-------|--------|-----------|
| `default` | Outlined, cor vermelha, contagem + delta | Nenhuma pill ativa |
| `active` | Borda grossa / sombra sutil, cor vermelha | 1º toque |
| `filter-active` | Fundo sólido vermelho, texto branco | 2º toque |
| `dimmed` | Opacidade 40% | Outra pill em `filter-active` |
| `zero` | Cor neutra (cinza), sem delta, "0" | Nenhum participante neste estado |

**Accessibility:** `aria-pressed` triple-state: `false` → `true` (scroll) → `mixed` (filter). VoiceOver: "Precisam de cuidado, filtro ativo."

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| **Default** | Dados carregados, ≥1 sinal 🔴 ou 🟡 | Layout completo | Todas |
| **Default (filtered)** | 2º toque numa SemaforoPill | Apenas seção selecionada visível, outras pills `dimmed` | Todas + 3º toque restaura |
| **Inbox Zero** | Todos 🟢, sem delta | Header + pills verdes + InboxZeroState | Filtro, tabs, pull-to-refresh |
| **Return** | `lastSeenAt` > 5 dias | ReturnBanner visível, deltas suprimidos | Todas + banner interactions |
| **Loading (initial)** | Primeiro carregamento, sem cache | Header + 3 skeleton pills + 3 skeleton cards. Sem filtro. | Tabs apenas |
| **Loading (refresh)** | Pull-to-refresh ou troca tenant/grupo | Spinner discreto, dados stale visíveis | Todas (dados stale) |
| **Error (network)** | Fetch falhou, sem cache | Card de erro + "Tentar novamente" | Retry, tabs |
| **Error (network+cache)** | Fetch falhou, cache disponível | Layout normal + banner offline dismissable | Todas (dados cached) |
| **Error (server)** | API 5xx | Card de erro, retry automático com backoff | Tabs, auto-retry |
| **Empty (no groups)** | Líder sem grupos atribuídos | Card explicativo | Tabs |

**Transições:**
```
[Loading initial] → ok → [Default] | [Inbox Zero] | [Return]
[Loading initial] → fail, no cache → [Error network]
[Loading initial] → fail, cache → [Error network+cache]
[Default] → 2º toque pill → [Default (filtered)] → 3º toque → [Default]
[Default] ↔ [Loading refresh]
[Return] → dismiss → [Default] | [Inbox Zero]
[Error network] → retry ok → [Default] | [Inbox Zero]
[Empty] → (sem transição automática)
```

## Global Behaviors

| Event | Behavior |
|-------|----------|
| **Pull-to-refresh** | Invalidate TanStack Query. Spinner no topo. Stale-while-revalidate. |
| **App resume** | Se staleTime expirou → auto-refresh silencioso. Se `lastSeenAt` >5d → ReturnBanner, sem auto-refresh silencioso. |
| **Deep link** `?grupo={id}` | Seleciona GrupoPill. UUID inválido ou não pertence → fallback "Todos", silencioso. |
| **Back button (Android)** | Home do líder → noop. Se veio de 01.3/01.5 → standard back stack. |

## Validation & Defensive Rules

**Input validation (parâmetros de entrada — página read-only):**

| Context | Parameter | Rule | Fallback |
|---------|-----------|------|----------|
| Deep link | `?grupo={id}` | UUID v7, pertence ao user | Silencioso → "Todos" |
| Tenant switch | `tenantId` | UUID v7, na lista do token | Token expirou → redirect login |
| Pull-to-refresh | Rate limit | Max 1/5s (client throttle) | Ignorado silenciosamente |
| App resume | `lastSeenAt` | ISO 8601 do localStorage | Corrompido → primeira visita |

**API data validation (defensiva, frontend):**

| Data | Validation | Fallback |
|------|-----------|----------|
| `participants[]` | Array não-nulo | `[]` → Inbox Zero |

| `participant.name` | String não-vazia | `""` → "Participante" |
| `participant.contextPhrase` | String | `null` → omite linha |
| `groups[]` | Array não-nulo | `[]` → sem filtro (só "Todos" implícito) |
| `nextMeeting` | `{ day, time }` ou null | `null` → InboxZeroState `without-meeting` |

## Technical Notes

- **Rendering:** CSR (página autenticada dentro de `/app/`). Não indexável.
- **Data fetching:** TanStack Query com staleTime longo (cache-first). `useRadarSignals(tenantId, groupId?)`.
- **State management:** Zustand para UI state (filtro ativo, pill state, banner dismissed). TanStack Query para server state.
- **Multi-tenancy:** `tenantId` via AsyncLocalStorage do token Keycloak. Nunca como parâmetro de função.
- **Performance:** TTI ≤2s Moto G4/G5. Skeleton loading. Stale-while-revalidate.
- **Accessibility:** WCAG AA. Redundância cor+ícone+texto em todos os sinais. `aria-pressed` triple-state nas pills.
