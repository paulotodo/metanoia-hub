## Overview

**Page Purpose:** Primeira tela autenticada da Juliana. Mostra seus grupos (inicialmente 1 — o que ela acabou de aceitar). Calma absoluta: 1 card, zero gráfico, zero porcentagem, zero badge, zero tour guiado. É a sala de estar digital — simples e acolhedora.

**User Situation:** Terça, 19h46. Juliana acabou de autenticar via Google (06.3). O convite foi aceito automaticamente. Ela vê 1 card: "Fundamentos da Fé". Precisa sentir: "tá, é isso. Meu grupo. Simples."

**Success Criteria:** Em ≤2 segundos, Juliana vê seu grupo e entende que pode tocar para ver mais. Zero confusão, zero sobrecarga, zero pedido de ação.

**Entry Points:**
- (1) Redirect pós-auth (06.3) — primeira vez
- (2) Login direto → ExperienceResolver detecta `Participante` → redirect aqui
- (3) Bottom tabs → "Meus Grupos"

**Exit Points:**
- (1) Toque no card → 06.5 Detalhe do Meu Grupo
- (2) Bottom tabs → outras áreas (quando houver)
- (3) Fechar app

**Route:** `/app/consumo/grupos`

---

## Reference Materials

**Strategic Foundation:**
- Epic 4 FR26 — Participante visualiza seus grupos
- Persona 05 — zero formulário, zero tour, zero badge
- UX-DR22–25 — Experiência consolidada `/app/consumo/`

**Design Constraints:**
- **Calma absoluta:** esta tela existe para ser simples, não para impressionar
- **Zero pedido de ação:** nenhum "Complete seu perfil", nenhum "Comece agora"
- **1 card no sunshine path:** Juliana tem 1 grupo. A tela suporta N grupos, mas o default é mínimo.
- **Sem BottomTabBar no MVP:** participante tem poucas áreas — tabs introduzidas quando houver conteúdo (Epic 8 R1b). Por ora, tela única.
- NFRs: TTI ≤2s, WCAG AA
- Glossário banido: dashboard, frequência, engajamento, score, ranking, check-in, trilha (ainda não existe no R1a)

|----------|-------------|

| State | Visual | Condition |
|-------|--------|-----------|
| `default` | White bg, shadow-sm | Normal |
| `pressed` | Scale-down 0.98, shadow-none | Toque ativo |

**Design decisions:**
- **"Ver meu grupo →"** em vez de botão — tom de convite, não de ação obrigatória. A seta indica navegabilidade.
- **Schedule mostrado** — Juliana vê quando é o próximo encontro sem entrar no detalhe. Útil para decidir se vai.
- **Sem status de presença** — participante nunca vê semáforo, nunca vê "você faltou X vezes". Zero.
- **Sem contagem de membros** — evita comparação social implícita.

## Technical Notes

- **Rendering:** CSR (autenticada, `/app/consumo/`).
- **Data fetching:** TanStack Query — GET `/api/v1/participant/groups` → 200. Response: `{ data: GroupCard[], meta: { firstVisit: boolean } }`. `staleTime: 30s`.
- **First visit flag:** Backend retorna `firstVisit: true` se nunca acessou antes. Usado para welcome message.
- **Gender-aware greeting:** Backend pode inferir gênero do nome para "Bem-vinda/Bem-vindo" ou usar neutro "Boas-vindas". Fallback seguro: "Boas-vindas, {firstName}."
- **Multi-tenancy:** `tenant_id` via AsyncLocalStorage. Participante vê apenas grupos do tenant ao qual pertence.
- **Accessibility:** WCAG AA. Cards como `role="article"` em `role="list"`. Touch target ≥48dp. Focus ring.
- **Domain event:** `participant.group.first_view` disparado na primeira visualização desta tela.
