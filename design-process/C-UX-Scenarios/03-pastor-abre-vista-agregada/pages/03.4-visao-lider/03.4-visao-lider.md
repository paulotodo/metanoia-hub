## Overview

**Page Purpose:** Ver o líder como pessoa, não como operador de grupo. Relembrar: quando foi a última conversa pastor→líder? O que o líder tem registrado? E o convite final: "O que você quer levar para essa conversa?" — um campo livre onde o pastor anota 1 frase de intenção pastoral.

**User Situation:** Domingo, 14h30. Pastor leu a timeline do Grupo Vida Nova (03.3). Clicou "Ver o líder desse grupo". Vê o João — não o grupo do João. Quer decidir: vale uma ligação esta semana? E se sim, com que tom abrir? Digita: "Perguntar como ele está se sentindo conduzindo esse grupo". Salva. Fecha o notebook com 1 nome e 1 pergunta no caderno mental.

**Success Criteria:** Em ≤3 minutos, pastor decide se vai procurar o líder e, se sim, anotou 1 frase de intenção. Ação completamente opcional — o pastor pode voltar sem anotar nada.

**Entry Points:**
- (1) "Ver o líder desse grupo" na 03.3
- (2) Deep link `/app/admin/igreja/lideres/{leaderId}`

**Exit Points:**
- (1) "Anotar para essa semana" → confirmação inline → volta para 03.2 ou 03.3
- (2) Back → 03.3
- (3) AdminSidebar → outras áreas
- (4) Fechar notebook (fim da sessão)

**Route:** `/app/admin/igreja/lideres/{leaderId}`

## Reference Materials

**Strategic Foundation:**
- Cenário 03 outline — `admin.outreach_intent` (design-driven requirement, story nova no Epic 6)
- Epic 6 FR60 — Vista agregada (drill-down até líder)
- Design Implication F — Improviso Sagrado: sistema nunca diz "ligue para o João"

**Design Constraints:**
- **Bloco de notas pastoral privado:** intenção é visível apenas ao pastor que escreveu (RLS `tenant_id + user_id`)
- **O líder nunca vê:** `target_leader_id` nunca é notificado nem tem acesso à intenção
- **Improviso Sagrado máximo:** campo livre, sem template, sem sugestão, sem categorias
- **Ação 100% opcional:** pastor pode sair sem anotar nada — zero culpa, zero prompt
- NFRs: TTI ≤2s, WCAG AA
- Glossário banido: monitorar, rastrear, frequência, célula, relatório, dashboard, rebanho, score, ranking, KPI

## Technical Notes

- **Rendering:** CSR (autenticada, `/app/admin/`).
- **Data fetching:** TanStack Query — GET `/api/v1/admin/church/leaders/{leaderId}` → 200. Response: `{ data: { leader: LeaderProfile, lastConversation: OutreachIntent|null, recentActivity: ActivityEntry[], currentWeekIntent: OutreachIntent|null } }`. `staleTime: 5min`.
- **Save intent:** POST `/api/v1/admin/outreach-intents` → 201. Body: `{ targetLeaderId, note, weekOf }`. Domain event: `pastor.outreach.intent`.
- **Edit intent:** PUT `/api/v1/admin/outreach-intents/{intentId}` → 200.
- **Delete intent:** DELETE `/api/v1/admin/outreach-intents/{intentId}` → 204.
- **RLS:** `outreach_intents` table scoped by `tenant_id + user_id`. O líder-alvo (`target_leader_id`) NUNCA tem acesso de leitura a esta entidade. É um bloco de notas pastoral 100% privado.
- **Data model:** `outreach_intents` — `{ id, tenant_id, user_id, target_leader_id, week_of, note, created_at, updated_at }`. Uniqueness constraint: `(tenant_id, user_id, target_leader_id, week_of)`.
- **Multi-tenancy:** `tenant_id` via AsyncLocalStorage. leaderId validado contra tenant do Admin Tenant.
- **Accessibility:** WCAG AA. Textarea com `aria-describedby` pointing to char counter. Sections as `role="region"` with `aria-labelledby`. Focus management on save confirmation.
