## Overview

**Page Purpose:** Tela de login existente (`apps/web/app/(public)/login/page.tsx`), com 1 adição crítica: link **"Esqueci minha senha"** abaixo do campo de senha. Sem esse link, líderes que cadastraram com email/senha e esqueceram a senha ficam em dead-end silencioso.

**User Situation:** Quarta, 6h15. Marcos abre o app (PWA). Sessão expirada. Vê tela de login.

**Why specified-light:** A tela de login é compartilhada com todos os cenários (01.1, 03.1, 06.2). Aqui documentamos apenas: (1) os 2 paths de recuperação, (2) a adição do link "Esqueci minha senha" (DDR da Story 2.9), (3) mensagens de erro pastorais.

---

## Two Recovery Paths

### Path A — Google OAuth (80% dos casos, ≤10s)

```
[Tela de login] → "Continuar com Google" → OAuth → Radar ✓
```

Trivial. Marcos toca 1 botão, Google seleciona conta automaticamente, redirect para `/app/gestao/radar`. Sem atrito.

### Path B — Password Recovery (20% dos casos, ≤3 min)

```
[Tela de login] → erra senha 2x → toca "Esqueci minha senha" → 07.2
```

O link "Esqueci minha senha" é o DDR exposto por este outline.

## DDR Addition: Link "Esqueci minha senha"

**OBJECT ID:** `07.1-F1`

| Property | Value |
|----------|-------|
| Component | link (text) |
| Visual | 14px, `text-muted`, abaixo do campo de senha, acima do botão "Entrar" |
| Translation Key | `auth.login.forgotPassword` |
| PT-BR | "Esqueci minha senha" |

| Behavior | Description |
|----------|-------------|
| `onTap` | Navega → 07.2 Recuperar Senha (`/recuperar-senha`) |

**Design decision:** Link discreto mas encontrável. Marcos olha pra baixo após errar a senha — o link está ali, sem precisar rolar.

## Error Messages (Pastoral Tone)

| Scenario | Translation Key | PT-BR |
|----------|-----------------|-------|
| Wrong password | `auth.login.error.wrongPassword` | "Essa senha não bateu. Tenta de novo ou usa 'Esqueci minha senha'." |
| Rate limited (3+ tentativas) | `auth.login.error.rateLimited` | "Muitas tentativas. Espera 5 minutinhos ou usa 'Esqueci minha senha'." |
| Generic error | `auth.login.error.generic` | "Algo deu errado. Tenta de novo?" |

**Design decisions:**
- **"Essa senha não bateu"** — tom casual, não "Invalid credentials"
- **Referência ao "Esqueci" no erro** — guia o Marcos para o recovery sem que ele precise procurar
- **"5 minutinhos"** — diminutivo pastoral, não "account locked for 300 seconds"
