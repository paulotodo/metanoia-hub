## Overview

**Page Purpose:** Criar nova senha. 2 campos (nova senha + confirmação), validação OWASP inline, botão "Salvar e entrar". Marcos digita, toca, e é redirecionado para o radar. ≤30 segundos nesta tela.

**User Situation:** Quarta, 6h17. Marcos tocou "Criar nova senha" no email (07.3). Chrome abre. Ele precisa criar uma senha nova rapidamente e voltar ao radar.

**Success Criteria:** Em ≤30 segundos, Marcos cria nova senha e é redirecionado ao radar. Zero campo além dos 2 necessários.

**Entry Points:**
- (1) Toque no CTA do email de reset (07.3)
- (2) Colagem direta da URL `/nova-senha/{token}`

**Exit Points:**
- (1) "Salvar e entrar" → 07.5 → Radar ✓
- (2) Token expirado → redirect para 07.1

**Route:** `/nova-senha/{token}` — rota pública, SSR, sem autenticação.

---

## Reference Materials

**Strategic Foundation:**
- FR83 / Story 2.9 — Password recovery
- Story 2.1 — OWASP password validation (já implementada)

**Design Constraints:**
- **2 campos apenas** — nova senha + confirmação. Zero "senha atual", zero pergunta de segurança.
- **Validação OWASP** — mínimo 8 chars. Sem regra absurda (maiúscula + símbolo + número + emoji).
- **Token 15 min** — se expirado, mensagem pastoral + redirect
- NFRs: TTI ≤2s, WCAG AA

## Technical Notes

- **Rendering:** SSR — rota pública `/nova-senha/{token}`.
- **Token validation:** GET `/api/v1/auth/reset-password/{token}/validate` → 200 (valid) / 404 (expired/invalid) / 409 (used). SSR validates on page load.
- **Save:** POST `/api/v1/auth/reset-password` → 200. Body: `{ token, newPassword }`. Backend calls Keycloak Admin API to reset password.
- **Auto-login:** After successful reset, backend creates session (JWT) and returns auth cookies. Frontend redirects to ExperienceResolver → radar.
- **OWASP:** Same validation as Story 2.1. Mínimo 8 chars. No absurd rules.
- **Accessibility:** WCAG AA. Auto-focus first field. Tab between fields. Enter = submit. Password toggle with `aria-label`. Error messages with `aria-live`.
- **Domain event:** `auth.recovery.completed` disparado no POST bem-sucedido.
