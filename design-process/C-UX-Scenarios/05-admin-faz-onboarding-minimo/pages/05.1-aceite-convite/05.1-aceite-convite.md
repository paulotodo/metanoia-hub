## Overview

**Page Purpose:** Primeira impressão pós-compra. O pastor clicou no link do email de ativação — esta tela confirma que ele está no lugar certo e convida a começar. Zero fricção, zero surpresa. O link é a porta; esta tela é o tapete de boas-vindas.

**User Situation:** Sábado, 14h40. Pastor na mesa do notebook, casa calma. Acabou de clicar "Clique aqui para começar" no email de ativação. Espera ver algo que confirme: "sim, é isso mesmo". Está cauteloso — não quer ser redirecionado para algo inesperado. Primeira interação com o produto real.

**Success Criteria:** Em ≤5 segundos, pastor entende onde está e o que precisa fazer. Toca "Aceitar e começar" com confiança, sem hesitação. Nenhuma informação solicitada nesta tela — é puro convite.

**Entry Points:**
- (1) Clique no link do email de ativação (caminho primário)
- (2) Colagem direta da URL `/convite/{token}` (edge case)

**Exit Points:**
- (1) "Aceitar e começar" → 05.2 Termos LGPD
- (2) "Ver os termos primeiro" → 05.2 Termos LGPD (scroll direto ao texto)
- (3) Fechar aba (abandono — sem consequência, token permanece válido 7 dias)

**Route:** `/convite/{token}` — rota pública, sem autenticação. Token de uso único, válido 7 dias.

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| **Default** | Token válido, página carregada | Layout completo | Aceitar, ver termos |
| **Loading** | Validando token (inicial) | Logo + skeleton | Nenhuma |
| **Token expired** | Token expirou (>7 dias) | Mensagem: "Esse link expirou" + instruções | Link para suporte |
| **Token used** | Token já foi usado | Mensagem: "Esse convite já foi aceito" + link login | Login |
| **Token invalid** | Token malformado | Mesma aparência de "expired" | Link para suporte |
| **Error (network)** | Falha de rede ao validar | Mensagem + retry | Retry |

**Transitions:**
```
[Loading] → token ok → [Default]
[Loading] → token expired → [Token expired]
[Loading] → token used → [Token used]
[Loading] → token invalid → [Token invalid]
[Loading] → network fail → [Error network]
[Default] → click accept → validating → [Loading 05.2]
```

## Global Behaviors

| Event | Behavior |
|-------|----------|
| **Browser back** | Volta ao email (ou última página) — sem estado a preservar |
| **Refresh** | Re-valida token. Se já usado → Token used state |
| **Dupla-aba** | Token válido em ambas. Primeira aba que completa o fluxo invalida o token para a segunda. |

## Validation & Defensive Rules

**Parameter validation:**

| Context | Parameter | Rule | Fallback |
|---------|-----------|------|----------|
| Route | `{token}` | String opaca, validada no backend | Inválido → Token invalid state |
| Token | Expiry | ≤7 dias desde criação | Expirado → Token expired state |
| Token | Usage | Uso único | Já usado → Token used state |

**Security:**
- Token não revela informação sobre o tenant em caso de erro (mensagens genéricas para invalid/expired)
- Rate limit: 10 tentativas/IP/hora para validação de token
- Nenhum dado do pastor exibido antes da autenticação

## Technical Notes

- **Rendering:** SSR — rota pública, indexável apenas se permitido (recomendação: `noindex` para páginas com token).
- **Token validation:** GET `/api/v1/invites/{token}/validate` → 200 (válido) / 404 (inválido/expirado) / 409 (já usado). Response não revela dados do tenant.
- **No auth required:** página pública, sem sessão.
- **Performance:** TTI ≤1.5s (página leve, SSR).
- **Accessibility:** WCAG AA. Botão com texto descritivo. Link de termos com underline. Focus ring visível no tab navigation (desktop).
- **Analytics:** Pageview + `invite.page.viewed` event. Não conta para ativação — apenas para funil de conversão.
