## O que foi difícil (Challenges)
- **LIÇÃO CENTRAL — features backend/full-stack passam em `--filter api` e quebram em runtime que SÓ o CI pega** (~6 ciclos de CI no total):
  - 14-2c: 3 correções de seletor E2E (sino duplicado no NavigationShell; `:visible` insuficiente no cold-start do CI → escopo estrutural determinístico via `data-testid`).
  - 14-3: enum em `packages/types` quebrou o build do `web` (Record exaustivo); `RESEND_API_KEY` sem default travou o boot da API nos jobs E2E/Axe; asset `.lua` não empacotado → `ENOENT` em `node dist`.
  - 14-4: fixture de snapshot do `@metanoia/types`; nome de fila BullMQ com `:` travou o boot; imports/matchers do spec do `web`.
  - **Causa-raiz**: a validação local da onda rodava `--filter api`, mas não `@metanoia/types`, `@metanoia/web`, `turbo build` web, nem o **boot real da API** (`start:e2e` + `/api/health`, onde `onModuleInit` vive).
- **CI `synchronize` não dispara run neste repo** — todo push à branch de PR exigiu `gh pr close+reopen`. Atrito em todas as stories. (Ruído correlato: runs cancelados pela concurrency aparecem como fails de 0-40s.)
- **`review-task` continua subnotificando** (confirma Epics 12 e 13): não pega bugs de boot/integração/lint. A validação local completa do PAI permaneceu indispensável.
- **Coordenação com produção em paralelo**: este host É produção; o operador editou `docker-compose.prod.yml` (deploy da 14-3) e oficializou via PR #183 enquanto a 14-4 rodava — o `stash pop` da sincronização conflitou; resolvido a favor da versão oficial de dev (a mudança já estava lá), dropando o WIP redundante.

## Lições-chave (Key Insights)
1. **Validar localmente TODOS os suites que o CI roda, não só `--filter api`**: `@metanoia/types` (schemas Zod), `@metanoia/web` (frontend), `turbo build --filter=@metanoia/web` (tipos compartilhados), e o **boot da API** (`node dist/main.js` + `/api/health`) para `onModuleInit`. É a evolução natural da lição "validação Postgres local" do Epic 13.
2. **Convenções de plataforma a cravar**: nome de fila BullMQ "bare" (sem `:` — o `BullMqService` injeta o prefix); env var nova obrigatória → adicionar aos jobs de CI que sobem a API (`${{ secrets.X || 'dummy' }}`); asset runtime não-`.ts` (.lua/.sql) → `compilerOptions.assets` no `nest-cli.json`.
3. **Gate OWASP no design paga**: pegar XSS/CRLF/BOLA/info-disclosure no plano é mais barato que no código.
